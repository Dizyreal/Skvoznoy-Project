Week 13: ML Summary

Задача:
Предсказать максимальную дневную магнитуду землетрясения по средней глубине, количеству событий, средней магнитуде, дню недели и месяцу.

Метрики:
- MAE (Mean Absolute Error) - средняя абсолютная ошибка в магнитуде
- R2 - доля объясненной дисперсии

Результаты:
- Baseline (предсказание средним): MAE = 0.45, R2 = -0.02
- Linear Regression: MAE = 0.44, R2 = 0.01
- Decision Tree: MAE = 0.41, R2 = 0.08

Вывод:
Модель незначительно лучше baseline (на 2-9%). Магнитуда слабо зависит от выбранных признаков. Для улучшения нужны дополнительные данные (сейсмическая история, тектонические особенности). Практическая ценность модели низкая.
