## Инкрементальность и идемпотентность

### Режимы запуска

- **full**: полная перезагрузка. Пересоздает raw, mart и таблицу в Postgres.
- **incremental**: добавляет только новые данные по watermark.

### State

Хранится в `data/state.json`:

- `last_watermark` - последняя обработанная дата
- `last_run` - время последнего запуска
- `mode` - режим последнего запуска

### Business key

`date` - уникальный идентификатор строки витрины.

### Watermark

Обновляется только после успешного выполнения всех этапов (extract -> transform -> load).

### Идемпотентность

- full: повторный запуск полностью заменяет таблицу
- incremental: проверяет существующие даты и не добавляет дубликаты

## Инкрементальность в Airflow

### Период одного DAG Run

Один DAG Run обрабатывает один день (daily grain). Период задается через `{{ ds }}` (logical date).

### Защита от дублей

- `load_period` удаляет строки за текущий период перед вставкой (DELETE + INSERT в одной транзакции)
- Retry безопасен: повторный запуск того же периода сначала удалит старые данные, затем вставит новые

### DQ Gate

DQ проверки запускаются **до** загрузки в Postgres. Если DQ возвращает FAIL, DAG падает и load не выполняется.

### Backfill

Backfill безопасен благодаря идемпотентной загрузке. Каждый период обрабатывается независимо.

### Артефакты

- raw: `data/raw/variant_15/raw_{{ ds }}.json`
- mart: `data/mart/mart_{{ ds }}.csv`
- dq*report: `data/dq_report*{{ ds }}.json`
