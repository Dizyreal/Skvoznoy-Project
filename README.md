## 🛠 Инструкция по запуску под Windows

### 1. Автоматическая настройка окружения

Для первоначальной настройки и установки всех зависимостей запустите командный скрипт. Скрипт автоматически найдет локальную установку Conda, создаст изолированное окружение `my_project_env` (Python 3.10) и установит библиотеки из `requirements.txt`.

**Способ А (Через консоль - Рекомендуемый):**

1. Откройте командную строку Windows (`cmd`).
2. Перейдите в папку скриптов:
   ```cmd
   cd scripts
   ```
3. Запустите скрипт:
   ```cmd
   setup_env.bat
   ```

**Способ Б (Двойным кликом):**

- Перейдите в папку `scripts/` через Проводник Windows и дважды нажмите на файл `setup_env.bat`. Окно терминала зафиксируется и не закроется автоматически по завершении процесса.

---

### 2. Запуск Smoke-теста

Скрипт автоматизации `setup_env.bat` включает в себя встроенный автоматический запуск smoke-теста в самом конце своей работы.

Если вы хотите выполнить smoke-тест **вручную** в любое другое время, используйте команду `conda run`, которая гарантирует выполнение кода строго внутри изолированного контекста проекта:

1. Откройте командную строку в корневом каталоге проекта.
2. Выполните команду:
   ```cmd
   C:\Users\dizy\miniconda3\Scripts\conda.exe run -n my_project_env python broken_env.py
   ```

**Ожидаемый успешный вывод теста:**

```text
python: C:\Users\dizy\miniconda3\envs\my_project_env\python.exe
pandas: 2.3.2
[OK] Настройка окружения успешно завершена!
```
